# TRAIT MAPPING STANDARD
## Convergent Archetype Framework (CAF)

Version: 1.0.0  

---

# 1. Purpose

To standardize trait extraction across symbolic domains.

Each domain must map archetypes into unified meta-trait categories.

---

# 2. Core Meta-Trait Categories

- Leadership
- Analytical Thinking
- Emotional Depth
- Creativity
- Discipline
- Intuition
- Stability
- Risk Orientation
- Social Expressiveness
- Power Dynamics

Each trait scored 0–1 per domain.

---

# 3. Trait Aggregation

FinalTraitScore(T) =  
Σ (DomainTraitValue(T))  
/  
ActiveDomains

---

# 4. Convergence Thresholds

0.80+ → Strong Reinforcement  
0.60–0.79 → Moderate Reinforcement  
0.40–0.59 → Balanced  
Below 0.40 → Weak Signal  

---

# 5. Conflict Traits

If domains split strongly (e.g., 4 high / 4 low):

Mark as Dual Archetype Tension.

---

# 6. Versioning Rule

Any trait category addition requires:

- Documentation update
- Version increment
- Cross-domain remapping

---

End of Trait Mapping Standard v1.0.0
