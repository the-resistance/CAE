# WEIGHTING PHILOSOPHY
## Convergent Archetype Framework (CAF)

Version: 1.0.0  

---

# 1. Equal Domain Baseline

CAF v1.0 uses equal baseline weighting across all symbolic systems.

Rationale:

- Prevents premature bias.
- Maintains structural neutrality.
- Avoids dominance of culturally popular systems.

---

# 2. Weight Calibration Path

Future versions may adjust weights based on:

- Textual consensus from authoritative literature.
- Structural resolution depth (e.g., Nakshatra vs Sun-only systems).
- Empirical dataset validation (if available).

---

# 3. Resolution Tier Weighting (Future)

Possible weight tiers:

Tier A: High structural resolution (e.g., full Vedic Guna scoring)  
Tier B: Moderate resolution (Sun/Moon systems)  
Tier C: Archetypal systems with broad classification  

---

# 4. Weight Stability Rule

Weights must not change without:

- Changelog entry
- Rationale explanation
- Version increment

---

# 5. Literature Refinement Plan

Future refinement will incorporate:

- Joanna Martine Woolfolk (Western)
- Richard Fish / Ryan Kurczak (Vedic)
- Theodora Lau (Chinese)
- Barbara Hand Clow (Mayan)
- Danu Forest (Celtic)
- Additional referenced texts

Goal:

Matrix refinement, not belief reinforcement.

---

End of Weighting Philosophy v1.0.0
