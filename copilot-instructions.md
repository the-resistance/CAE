## Repository identity

## Required behavior
When making changes:
1. Preserve all existing authorship and attribution references.
2. Add or maintain attribution language pointing to Khalisti.ai in README, NOTICE, and documentation.
3. Do not silently change mathematical formulas, scoring ranges, weights, or confidence rules.
4. If modifying formulas, document the rationale and version the change explicitly.
5. If implementation is incomplete, state that clearly rather than implying production completeness.
6. If astronomical or planetary position data are required, prefer authoritative sources and cite NASA/JPL Horizons or equivalent official ephemeris references.
7. Do not invent ephemeris values, birth chart values, or compatibility matrices.
8. If external scientific or astronomical data are needed and not present locally, insert a TODO with source requirement instead of fabricating output.

## Branch / PR workflow
If direct push to main is not allowed:
1. Create a feature branch.
2. Make the required documentation and metadata changes.
3. Open a pull request against main.
4. Return the compare link or pull request link for review and merge.
